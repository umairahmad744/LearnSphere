# **App Name**: LearnSphere

## Core Features:

- Video Content Display: Showcase free and premium video courses, with integration for embedded videos from platforms like YouTube, TikTok, and Instagram.
- User Authentication: Implement email login using NextAuth for user management. Allow the creation of student role accounts with free membership tiers.
- Premium Content Gating: Restrict access to premium videos and resources based on membership status.
- Interactive Quizzes: AI powered tool that can automatically create quizzes and assess responses for premium content.
- Student Dashboard: Provide a user-friendly dashboard where students can access free and premium content, view grades, and track progress.
- Community Forum: Integrate a discussion section under each video for student interaction and Q&A.
- FAQ Section: Add a comprehensive FAQ section and contact form to address common questions and provide support.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to inspire trust, learning, and confidence. This choice avoids the common cliche of educational sites using green.
- Background color: A light, desaturated blue (#E5F5F9), providing a clean and unobtrusive backdrop.
- Accent color: A warm orange (#F2994A) as an analogous accent, to highlight calls to action and interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern, readable, and neutral appearance that works well for both headlines and body text.
- Use a set of consistent and clean icons, related to education and learning, for easy navigation.
- Implement a responsive design to ensure the platform is accessible and usable on all devices, from desktop to mobile.
- Incorporate subtle transitions and animations to enhance the user experience and provide feedback on interactions.
